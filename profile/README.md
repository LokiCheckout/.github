# Loki Checkout

**A fast, flexible and developer-friendly checkout for Magento 2.**

Loki Checkout is a modern replacement for the default Magento checkout, built with performance, accessibility and extensibility in mind.

Powered by **Loki Components, Alpine.js and Tailwind CSS**, it combines modern frontend technology with familiar Magento development patterns: XML layout, Blocks, ViewModels and PHTML templates. And not just for Hyvä Themes, but also Luma-based themes and Breeze.

The result? A checkout that is fast for customers and straightforward for developers to customize.

### Why Loki Checkout?

- **Built for performance** — Fast page loads, near-instant updates and fewer unnecessary loaders.
- **Developer-friendly** — Extend checkout functionality using familiar Magento patterns, without fighting the underlying architecture.
- **Component-based** — Customize checkout steps, fields and layouts through reusable Loki Components.
- **Theme-independent** — Works with Hyvä, Luma and Breeze.
- **Accessibility & security** — Built with WCAG accessibility and strict Content Security Policy (CSP) in mind.
- **Modular by design** — Add only the features and integrations your store requires.

### Get started

Whether you're building a new Magento store, replacing the default checkout or extending an existing implementation, these resources will help you get started.

```bash
composer require loki-checkout/magento2-core
bin/magento module:enable `bin/magento module:status | grep -E 'Yireo|Loki'`
```
